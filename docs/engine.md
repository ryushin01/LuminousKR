# 조합 원리

LuminousKR이 자모 24자의 뼈대로 한글 11,172자를 만드는 과정입니다. 코드는 `src/entities/font`와 `src/shared/lib`에 있습니다.

## 1. 뼈대 모델

자모는 획의 **가운데 선(뼈대)** 만 저장합니다(`model/types.ts`).

| 획   | 저장 값                                            |
| ---- | -------------------------------------------------- |
| 경로 | 점 목록, 닫힘 여부(ㅁ처럼), 매끄러움(캣멀-롬 곡선) |
| 타원 | 중심, 가로·세로 반지름 (ㅇ, ㅎ)                    |

좌표는 자모가 놓이는 **틀(box)** 안에서 0~1로 정규화합니다. 틀 크기가 바뀌어도 그림이 따라갑니다.

## 2. 여섯 가지 배치

음절은 중성 모양과 받침 유무에 따라 여섯 틀 가운데 하나로 짜입니다(`model/layout.ts`의 `DEFAULT_LAYOUTS`).

| 배치 | 예  | 중성                             | 받침 |
| ---- | --- | -------------------------------- | ---- |
| A    | 가  | 세로(ㅏ ㅐ ㅑ ㅒ ㅓ ㅔ ㅕ ㅖ ㅣ) | 없음 |
| B    | 고  | 가로(ㅗ ㅛ ㅜ ㅠ ㅡ)             | 없음 |
| C    | 과  | 섞임(ㅘ ㅙ ㅚ ㅝ ㅞ ㅟ ㅢ)       | 없음 |
| D    | 각  | 세로                             | 있음 |
| E    | 곡  | 가로                             | 있음 |
| F    | 곽  | 섞임                             | 있음 |

자모의 기본 그림은 **기본 배치**(초성 A, 세로 모음 A, 가로 모음 B, 섞임 모음 C, 종성 D)의 틀 기준이고, 다른 배치에서는 그 틀 크기에 맞춰 늘이거나 줄입니다. 선은 틀에 맞춰 늘이되, 타원은 기하 평균으로 크기를 맞추고 늘임을 1.12배까지로 제한해 ㅇ이 지나치게 납작해지지 않게 합니다.

특정 배치만 모양을 따로 그린 것을 **변형(벌)** 이라 하고, 있으면 그 배치에서 기본 그림 대신 씁니다. 옛 조합형 글꼴의 벌 개념과 같습니다.

## 3. 파생 규칙

직접 그리지 않은 43자는 다른 자모로 만듭니다(`model/derivation.ts`).

| 갈래                  | 규칙                                        | 변형 이어받기                    |
| --------------------- | ------------------------------------------- | -------------------------------- |
| 쌍자음 ㄲ ㄸ ㅃ ㅆ ㅉ | 같은 자음 둘을 좌우에                       | 예 (같은 초성 자리)              |
| ㅐ ㅒ ㅔ ㅖ           | 세로 모음 + ㅣ                              | 예                               |
| 섞임 모음 7자         | 가로 모음 → 배치의 Vh 틀, 세로 모음 → Vv 틀 | 아니요                           |
| 홑받침 14자           | 같은 초성의 **기본 그림**을 받침 틀에       | 아니요 (초성 변형은 초성 자리용) |
| 쌍받침·겹받침 13자    | 받침 둘을 좌우에 (ㄺ = ㄹ + ㄱ)             | 예                               |

나란히 놓는 두 자모의 사이는 획 굵기에 비례합니다(`resolveOptionsFor`). 그림을 찾는 순서는 `배치 변형 → 기본 그림 → 파생 규칙`입니다(`lib/resolve.ts`).

## 4. 굵기 입히기와 곡선 맞춤

`lib/outline.ts`가 뼈대를 윤곽으로 바꿉니다.

1. **좌표 변환**: 음절 좌표를 글꼴 좌표(1em = 1000, y 위로)로. 획 바깥이 글자 너비·높이 안에 들도록 뼈대 범위는 굵기의 절반만큼 줄입니다.
2. **펼치기**: 매끄러운 경로는 구심 캣멀-롬 스플라인을 베지어로 바꿔 4단위 간격으로, 타원은 둘레 길이에 맞춰 점으로 펼칩니다.
3. **두께 입히기**: Clipper2의 오프셋(`ClipperOffset`)으로 끝 모양(둥근·각진·잘린)과 꺾임(둥근·뾰족·깎은)에 맞춰 부풀리고, 겹친 획은 하나로 합칩니다. 가로·세로 굵기 차이(대비)는 x축을 줄인 공간에서 같은 두께로 부풀린 뒤 되돌려 만듭니다(타원 펜 효과).
4. **곡선 맞춤**(`shared/lib/geometry/fit-curve.ts`): 오프셋 결과는 둥근 부분이 잘게 나뉜 다각형입니다. 1단위보다 가까운 점과 바늘처럼 튄 점을 지운 뒤, 긴 변은 직선으로 두고 짧은 변이 이어진 구간만 Schneider 알고리즘으로 3차 베지어에 맞춥니다. 직선과 곡선이 만나는 곳은 접선을 이어 매끄럽게 합니다.
5. **기울기·정수화**: 기울기는 글자 가운데 높이를 기준으로 기울이고, 좌표를 정수로 맞춥니다. 바깥 윤곽은 반시계(PostScript 규칙), 구멍은 시계 방향입니다.

굵기를 나중에 입히므로, ㄲ의 반쪽 ㄱ이나 받침 ㄹ처럼 작게 놓인 획도 다른 획과 두께가 같습니다.

## 5. 음절 조합과 캐시

`lib/composer.ts`의 `Composer`는 `자모 × 배치`마다 윤곽을 한 번만 계산해 둡니다(최대 약 250개). 음절은 초성·중성·종성 조각을 모아 만들고, 조각의 다각형 경계가 서로 겹칠 때만 다시 합쳐 곡선을 맞춥니다. 섞임 모음처럼 떨어진 조각이 있는 자모는 다각형마다 경계를 따로 비교해, 쓸데없이 다시 합치지 않게 했습니다(조합 3.2초 → 0.6초).

## 6. 글꼴 파일

| 항목      | 값                                                                                             |
| --------- | ---------------------------------------------------------------------------------------------- |
| 글리프    | `.notdef`, 빈칸, 호환 자모 51자(U+3131–3163), 한글 음절 11,172자(U+AC00–D7A3)                  |
| 윤곽      | CFF(PostScript), opentype.js `Font.toArrayBuffer()`                                            |
| 세로 기준 | 1em = 1000, 위 880, 아래 −120, 글자 몸은 가운데 380 기준                                       |
| 이름      | 영문 이름(모든 플랫폼) + 한국어 이름(Windows, 언어 0x0412), PostScript 이름                    |
| OS/2      | 굵기 등급(획 굵기에서 환산), 한국어 완성형 코드 페이지, fsType 0(설치 가능)                    |
| WOFF      | 표마다 zlib(`CompressionStream('deflate')`)으로 압축, 줄지 않는 표는 그대로 (3.8MB → 약 210KB) |

전체 빌드는 Web Worker(`api/engine.worker.ts`)에서 돌고, 진행 상황을 256글리프마다 보냅니다. 미리보기용 작은 글꼴(입력한 글자만)은 다른 워커에서 만들어 `FontFace`로 등록합니다. 취소하면 워커를 끝내고 다음 요청 때 새로 띄웁니다(`shared/lib/worker-rpc`).
