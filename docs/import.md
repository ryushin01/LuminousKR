# 손글씨 가져오기

인쇄한 양식에 자모를 손으로 그려 찍거나 스캔해서 올리면 획의 뼈대를 찾아 프로젝트에 넣습니다. 코드는 `src/pages/import`(양식·인식)와 `src/shared/lib/image`(이미지 처리), `src/shared/lib/pdf`(PDF 쓰기)에 있습니다. 모든 처리는 브라우저 안에서 하고, 사진·PDF는 어디에도 보내지 않습니다.

## 1. 양식 PDF

`lib/template-pdf.ts`가 외부 라이브러리 없이 PDF 1.7을 씁니다(`shared/lib/pdf`).

| 요소 | 내용 |
|---|---|
| 표식 | 네 모서리의 22pt 검은 네모. 원근을 바로잡는 기준점 |
| 양식 번호 | 위쪽 가운데 10pt 네모 넷: 시작 비트(늘 칠함) + 번호 3비트 |
| 칸 | 5열 격자, 칸 하나가 음절 정사각형(86pt). 진한 점선이 그 자모의 틀, 연한 점선은 같은 배치의 다른 자모 자리 |
| 글자 | 한글은 조합기의 기본 프리셋 글리프 윤곽을 그대로 경로로 그림(글꼴을 넣지 않음), 영문·숫자는 PDF 기본 글꼴 Helvetica |

양식은 세 종류입니다: 기본 자모 24자(1번), 겹자모·섞임 모음 16자(2번), 받침 14자(3번).

## 2. 파일 읽기

- 그림(PNG·JPEG·WebP·GIF)은 `createImageBitmap`으로 엽니다.
- PDF는 올렸을 때만 pdf.js를 불러와 쪽마다 2.5배(약 180dpi)로 렌더링합니다. 판형이 커도 쪽당 2,500만 화소를 넘지 않게 배율을 줄입니다.
- 한 파일에서 6쪽까지 읽고, 넘는 쪽은 건너뛰었다고 쪽 수와 함께 알립니다.
- 그림(`ImageBitmap`)은 복사 없이 인식 워커로 넘기고, 워커가 `OffscreenCanvas`로 회색조로 바꿉니다(긴 변 1,800px까지 줄임).

## 3. 인식 (`lib/recognize.ts`, Web Worker)

1. **표식 찾기**: 적응형 이진화(Bradley–Roth, 그림자·조명 차이에 강함) → 연결 요소 → 채움 비율·가로세로 비율이 네모에 가까운 덩어리 중 네 모서리에 가장 가까운 것.
2. **원근 바로잡기**: 양식의 표식 위치(pt)와 사진의 표식 위치로 호모그래피(DLT)를 구합니다.
3. **양식 번호 읽기**: 비트 칸 가운데가 종이보다 어두운지 봅니다. 표식 순서를 네 방향으로 돌려 보며 시작 비트가 맞는 방향을 고르므로 뒤집혀 찍힌 사진도 됩니다.
4. **칸 떠내기**: 칸마다 160×160으로 바로잡아 떠내고, 종이 밝기(밝은 쪽 분위수)의 58%보다 어두운 곳만 잉크로 봅니다. 연한 안내선과 칸 테두리, 작은 잡티는 빠집니다.
5. **뼈대 만들기**: Zhang–Suen 세선화로 한 픽셀 두께의 가운데 선을 만듭니다. 잉크 넓이 ÷ 뼈대 길이로 펜 굵기를 잽니다.
6. **획 추적**(`shared/lib/image/trace.ts`): m-인접으로 이웃을 세어 끝점·교차점을 찾고, 교차점 픽셀 무리를 한 마디로 묶은 뒤 가지를 따라갑니다. 굵은 펜에서 생기는 짧은 끝가지는 지우고(마디의 가지 수는 고리의 양 끝을 둘로 세므로 ㅇ에 붙은 꼬리도 지움), 교차점에서 곧게 이어지는 가지끼리 한 획으로 잇습니다(ㅏ의 세로획이 가지에서 끊기지 않음). 끝점이 없는 고리는 닫힌 획이 되고, 타원에 가까우면 타원(ㅇ)으로 바꿉니다.
7. **정리**: RDP로 점을 줄이고(직선이 아니라 선분까지의 거리로 재서, 되돌아가는 획의 끝을 지킴), 격자에 맞추기를 켜면 24칸 격자로 맞춥니다.

## 4. 적용

인식한 칸은 바로잡은 칸 그림과 찾은 뼈대를 나란히 보여 주고, 고른 자모만 그 자모의 **기본 그림**으로 넣습니다(되돌리기 한 번으로 취소). 자모마다 하나만 고를 수 있어서, 하나를 고르면 같은 자모의 다른 칸은 풀립니다. 같은 자모를 여러 번 올리면 마지막에 올린 파일의 것을 고릅니다(먼저 올린 파일이 늦게 끝나도 올린 순서를 따름). 한 쪽의 인식이 실패해도 그 쪽만 알리고 다음 쪽과 파일을 계속 읽으며, 화면을 떠난 뒤 끝난 인식 결과는 버립니다. 펜 굵기를 글꼴 굵기로 가져오기를 켜면 고른 칸의 평균 펜 굵기로 획 굵기도 바꿉니다.

양식 없이 그림 한 장을 올리면, 잉크가 있는 범위를 잘라 고른 자모의 틀에 맞춰 놓습니다.

## 검사

- 단위: 합성한 양식 그림(원근·기울기·한쪽이 어두운 조명·뒤집힘)에서 양식 번호와 칸별 획(ㄱ 한 획, ㅇ 타원, ㅏ 두 획) 인식, 표식이 없을 때의 안내, 세선화·추적(꺾임·+자 교차·고리·꼬리 달린 고리), 되돌아가는 획의 단순화, 호모그래피, PDF 교차 참조 표.
- 가져오기 상태: 겹쳐 올린 파일의 순서, 자모마다 하나 고르기와 펜 굵기 평균, 인식 실패 뒤 계속 읽기, 건너뛴 쪽 안내, 화면을 떠난 뒤 결과 버리기와 그림 닫기. 후보 목록 화면에서 같은 자모의 체크 상자를 고를 때 앞의 것이 풀리는지.
- E2E: 앱이 만든 양식 PDF를 받아 다시 올리면 pdf.js로 렌더링해 양식을 알아보고 빈 칸 안내, 캔버스로 그린 '손으로 채운 양식 사진'을 올려 세 자모를 인식하고 적용한 뒤 작업실에서 확인.
