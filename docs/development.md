# 개발 가이드

## 구조

[Feature-Sliced Design v2.1](https://feature-sliced.design) 계층을 따르고 `pnpm lint:fsd`(Steiger)로 검사합니다. 슬라이스는 공개 API(`index.ts`)로만 가져옵니다.

| 계층 | 슬라이스 | 하는 일 |
|---|---|---|
| app | (세그먼트) `routes`, `layout`, `lib`, `styles` | 라우터, 본문 바로가기·배경·머리글·바닥글·오류 경계, 되돌리기 단축키, 전역 스타일과 웹 폰트 |
| pages | home, studio, import, preview, export, guide, not-found | 화면. 한 화면에서만 쓰는 코드는 그 화면 슬라이스 안에 둡니다 (예: 그리기 판 편집기, 손글씨 양식·인식 워커) |
| widgets | site-header, cosmos-backdrop | 머리글과 전체 메뉴(`<dialog>`), WebGL 배경 |
| features | adjust-style, manage-project, autosave-status, app-update | 획 스타일 조절, 프로젝트 저장·열기 (작업실·미리보기·내보내기에서 함께 씀), 자동 저장 알림·새로 고침 안내(앱 전체) |
| entities | font | 자모 모델·배치·파생 규칙, 조합 엔진, 조합 워커, 글리프 표시 |
| shared | lib(hangul, geometry, font-file, pdf, image, worker-rpc …), ui, config | 업무와 무관한 도구와 공용 UI |

경로 별칭은 `@/` → `src/`입니다. 같은 슬라이스 안에서는 확장자를 붙인 상대 경로(`./layout.ts`)로 가져옵니다.

## 명령

| 명령 | 설명 |
|---|---|
| `pnpm dev` | 개발 서버 (`http://localhost:5173`) |
| `pnpm build` | 프로덕션 빌드 + 화면별 HTML 사본(`scripts/postbuild.mjs`) |
| `pnpm build:all` | 앱 빌드 뒤 Storybook을 `dist/storybook`에 빌드 |
| `pnpm preview` | 빌드 결과 띄우기 (`http://localhost:4173`) |
| `pnpm lint` / `lint:fsd` / `format:check` / `typecheck` | ESLint / Steiger / Prettier / TypeScript |
| `pnpm test` | Vitest 단위·화면 테스트 |
| `pnpm test:e2e` | Playwright E2E (먼저 `build:all`) |
| `pnpm storybook` | Storybook 개발 서버 |
| `pnpm fonts` | 한글 웹 폰트(LuminousSans)의 화면 글자 파일과 조각 다시 만들기 (fontTools 필요) |
| `node scripts/screenshots.mjs` | README 화면 사진 다시 찍기 (먼저 `build`) |

## 테스트

- **엔진**: 한글 조합표, 곡선 맞춤(원·사각형·둥근 끝), 스플라인, OTF 쓰기와 다시 읽기, WOFF 규격·압축 해제 비교, 워커 RPC(진행·오류·취소), 배치·파생 규칙, 획 두께가 틀 크기와 무관한지, 음절 윤곽이 글자 틀 안에 드는지, 프로젝트 파일 검사·되돌리기.
- **인식**: 합성한 양식 그림(원근·기울기·한쪽이 어두운 조명·뒤집힘)에서 양식 번호와 칸별 획 인식, 세선화·뼈대 추적(꺾임·교차·고리), 호모그래피, 적응형 이진화, PDF 교차 참조 표, 양식 비트, 가져오기 적용·되돌리기.
- **자동 저장**: 0.4초 뒤 저장과 탭을 닫기 직전 바로 저장, 저장 공간 초과·막힌 저장소 알림, 읽지 못한 저장을 지우지 않고 보관(보관하지 못하면 받거나 버릴 때까지 저장 멈춤), 다른 탭의 저장을 받아 맞추고 되돌리기 기록 비우기, 늦게 온 지난 이벤트·읽지 못하는 다른 탭 저장은 무시.
- **복원력**: 브라우저별 조각 받기 실패 문구 알아보기, 워커 스크립트를 받지 못하면 `WorkerLoadError`와 알림, 끝난 요청의 취소 처리기 떼기, 오류 화면(받지 못함은 새로 고침만, 그 밖은 다시 시도), 되돌리기 단축키 판정(글자 입력칸만 제외).
- **화면**: 그리기 편집기(점 찍기·닫힌 획·원·취소·옮기기·자동 자모 가져오기·배치 변형), 내보내기(두 번 눌러도 한 번만, 실패·취소 처리, 입력 검사), 탭 키보드 조작, 입력칸 오류 연결, 메뉴 대화상자 초점 복귀.
- **E2E**(프로덕션 빌드): 모든 화면 axe(WCAG 2.2 AA 태그) 위반 없음, 화면 폭 320~1440px 가로 넘침 없음, 본문 바로가기, 메뉴 초점 가두기와 복귀, 키보드만으로 그리기, 포인터 그리기와 되돌리기, 자동 저장, 두 탭에서 고친 작업이 서로 덮이지 않고 맞춰지기, 저장 실패 알림, 읽지 못한 저장 받기·지우기, 보관할 공간이 없으면 받기 전까지 덮어쓰지 않기, 바꾸고 바로 닫아도 저장, 배포 뒤처럼 화면 조각·워커를 받지 못하면 오류 화면과 새로 고침 안내, 첫 로딩 레이아웃 이동(CLS) 0.02 미만(4화면 × 2너비), 화면별 HTML의 조각 미리 받기, 매니페스트·아이콘·공유 미리보기, 모든 화면 CSP 위반 없음, 포인터로 찍은 뒤 Enter로 마치기, 라디오·체크박스에 초점이 있어도 되돌리기, 미리보기에서 되돌리기 단축키, 11,172자 OTF·WOFF 내려받아 서명(`OTTO`·`wOFF`) 확인, 미리보기 글꼴과 588자 표, Storybook 모든 스토리 axe 검사, 앱이 만든 양식 PDF를 다시 올려 pdf.js로 알아보기, 손으로 채운 양식 사진을 인식해 적용하기, 배경 움직임 멈춤 버튼.

jsdom에는 Web Worker가 없어 `vitest.setup.ts`에서 답하지 않는 워커로 둡니다. 실제 워커 동작은 E2E에서 확인합니다. E2E는 `reducedMotion: 'reduce'`로 돌립니다(앱은 이 설정이면 배경을 멈춤). CI처럼 GPU가 없으면 앱이 WebGL 배경 대신 CSS 배경을 쓰므로(소프트웨어 렌더러 거르기), README 화면 찍기(`pnpm screenshots`)만 macOS의 Metal로 배경을 그립니다.

## 자동 저장

작업은 localStorage `luminous-kr:project:v1`에 프로젝트 전체를 JSON으로 저장합니다(`entities/font/model/persistence.ts`, `store.ts`).

| 상황 | 동작 |
|---|---|
| 고칠 때 | 0.4초 동안 더 바뀌지 않으면 저장. 탭을 닫거나 숨길 때(`pagehide`·`visibilitychange`)는 기다리지 않고 저장 |
| 저장 실패 | 저장 공간 초과·막힌 저장소를 화면 아래 경고(`role="alert"`)로 알리고, 다음 저장이 성공하면 거둠 |
| 다른 탭이 저장 | `storage` 이벤트가 오면 이벤트 값이 아니라 **지금 저장된 값**을 읽어(쌓였다 늦게 온 지난 이벤트를 거름), 이 탭이 마지막으로 쓰거나 맞춘 값과 다를 때만 그 작업으로 맞추고 되돌리기 기록을 비움(전체 스냅숏이라 다른 탭의 변경까지 되돌리지 않게). 이 탭은 다시 쓰지 않음 |
| 두 탭이 함께 고침 | 이 탭에 아직 쓰지 못한 변경(0.4초를 기다리는 중이거나 저장이 실패함)이 있을 때 다른 탭의 저장이 오면, 지금 보고 있는 탭의 변경이 가장 나중이므로 맞추지 않고 바로 씀(다른 탭이 이것을 받아 맞추며 알림). 다시 써도 실패하면 이 탭의 작업을 메모리에 두고 실패 알림을 유지. 전체 스냅숏이라 거의 동시에 고친 두 편집을 합치지는 않음 |
| 읽지 못한 저장 | 지우지 않고 원문마다 새 열쇠 `luminous-kr:project:v1:unreadable:<시각>`에 복사한 뒤 알림(목록 하나를 읽고-고치고-쓰지 않아 다른 탭과 서로 덮지 않음, 같은 원문은 한 번만). 원래 자리는 비우지 않음(그사이 다른 탭이 쓴 새 작업을 지우지 않게, 보관했으니 다음 저장이 덮어써도 됨). 화면에서 하나씩 받거나(한 번에 여러 파일을 받으면 브라우저가 막을 수 있음) 지울 수 있고, 다른 탭이 보관하거나 지우면 맞추며, 지울 때는 화면에 보여 준 원문의 열쇠만 지우고, 그 원문이 아직 원래 자리에 있으면 지금 작업으로 바로 써서 새로 고쳐도 다시 보관되지 않게 함. 저장 공간이 모자라 보관하지 못하면 원래 자리에 두고 **'원래 작업 버리기'를 누르기 전까지 자동 저장을 멈춤**(받기만으로는 놓지 않음 — 내려받기가 막혀도 알 수 없으므로). 그사이 다른 탭이 그 자리를 덮어쓰면 저장을 다시 켜고, 원문은 이 탭에서만 받을 수 있다고 알림(새로 고침 안내도 막음, 새로 고치기 직전에 저장소를 읽어 원래 자리·보관 열쇠에 같은 원문이 없는지 확인). 다른 탭이 같은 원문을 보관하면 놓고 저장을 다시 켬. 놓거나 버릴 때 다른 탭이 원래 자리를 이미 새 작업으로 바꿨으면(이벤트 전이라도) 덮지 않고 받아 맞춤 |
| 읽지 못하는 다른 탭 저장 | 더 새 버전의 형식 등으로 저장되면 맞추지 않고, 그 작업을 덮어쓰지 않도록 **이 탭의 자동 저장을 멈추고** 새로 고침을 안내. storage 이벤트가 오기 전에 저장하려 해도, 쓰기 직전에 저장된 값을 확인해 본 적 없는 읽지 못하는 원문이면 덮어쓰지 않고 멈춤. 나중에 다른 탭이 읽을 수 있는 작업을 저장하면 멈춤을 풀고, 멈춘 동안 이 탭에서 고친 것이 있으면 맞추기 전에 먼저 씀 |

운영 주소의 출처(`ryushin01.github.io`)는 다른 GitHub Pages 프로젝트와 함께 쓰므로 저장 공간(약 5MB)도 나눠 씁니다. 큰 작업은 프로젝트 파일(.json)로 저장해 두라고 안내합니다.

## 배포 뒤 열린 탭

GitHub Pages는 배포할 때 이전 파일을 남기지 않아, 배포 전에 연 탭이 아직 받지 않은 화면 조각·워커·pdf.js를 찾으면 404가 됩니다. `shared/lib/app-update`가 이런 오류(브라우저마다 다른 문구, `vite:preloadError`, `WorkerLoadError`)를 알아보고 앱 전체에 알리면, 화면 아래 새로 고침 안내(`features/app-update`)가 나타납니다. 화면을 그리다 난 오류는 `app/layout`의 오류 경계(`RouteError`)가 받습니다. 새로 고침은 기다리던(또는 실패한) 자동 저장을 먼저 쓰고, 새로 고치면 잃는 것이 남으면 새로 고치지 않고 까닭(`ReloadBlock`: 저장 공간 초과 등으로 쓰지 못한 변경, 이 탭에만 남은 원래 작업, 둘 다)을 알린 뒤 버리고 새로 고칠지를 따로 고르게 합니다. 버리기는 알린 까닭에만 듣고, 그 뒤 잃을 것이 늘었으면 새로 고치지 않고 늘어난 까닭으로 다시 확인받습니다.

## 글꼴

화면의 제목과 본문은 같은 짝을 씁니다. 영문·숫자는 **Syne**, 한글은 **IBM Plex Sans KR**입니다(`src/app/styles/tokens.css`의 `--font-display`·`--font-body`). IBM Plex Sans KR은 OFL 예약 이름(Plex) 때문에 이름을 바꾼 `LuminousSans`로, 화면 문구에 쓰인 글자만 담은 파일과 나머지 글자 조각을 `pnpm fonts`로 만듭니다(fontTools 필요). 빠진 글자가 있으면 `fonts.test.ts`가 실패합니다.


## 접근성 점검

KWCAG 2.2 항목을 직접 확인한 내용입니다.

| 항목 | 처리 |
|---|---|
| 5.1.1 대체 텍스트 | 글리프 그림은 숨기고 글자를 숨긴 텍스트로 함께 둠, WebGL 배경·진행 그림은 꾸밈(aria-hidden) |
| 5.3.1 표 구성 | 588자 표·규칙 표에 caption·scope, 가로 스크롤 영역에 이름과 tabindex |
| 5.4.3 명도 대비 | 모든 글자색 4.5:1 이상(토큰 계산), 선택된 밝은 칸 위 꼬리표 색 보정 |
| 6.1.1 키보드 | 그리기 판(application 역할)에서 화살표·스페이스·Enter·Esc·Delete, 획 옮기기 버튼, APG 탭 |
| 6.1.2 초점 | 화면을 옮기면 새 화면 h1로 초점, 메뉴를 닫으면 여는 버튼으로 복귀, 만드는 중에도 버튼 초점 유지(aria-disabled) |
| 6.1.4 문자 단축키 | 글자 하나 단축키는 그리기 판에 초점이 있을 때만 |
| 6.2.2 정지 | 배경 움직임 멈추기 버튼, 운영체제 '동작 줄이기'면 처음부터 멈춤 |
| 6.4.1 반복 영역 건너뛰기 | 본문 바로가기 |
| 6.4.2 제목 | 화면마다 문서 제목, 정적 HTML 사본에도 제목 |
| 6.5.1 단일 포인터 | 점은 누르기만으로 찍고, 끌기(꼭짓점 이동)는 버튼으로도 가능 |
| 7.3.1 오류 정정 | aria-invalid(잘못된 값일 때만) + aria-describedby·aria-errormessage, 원인과 고치는 방법, 첫 오류 칸으로 초점 |

화면 낭독기로 직접 들어 보는 확인(VoiceOver, NVDA)은 사람이 해야 합니다.
